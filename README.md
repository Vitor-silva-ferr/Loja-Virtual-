# 🛒 Loja Virtual React

Sistema de loja virtual fictícia desenvolvido com ReactJS, consumindo uma API para listagem de produtos e gerenciamento de carrinho de compras.

## 🚀 Tecnologias Utilizadas

* ReactJS
* JavaScript
* React Router DOM
* React Toastify
* API REST
* CSS

---

## 📦 Funcionalidades

✅ Listagem de produtos via API
✅ Adicionar produtos ao carrinho
✅ Remover produtos do carrinho
✅ Cálculo automático do valor total da compra
✅ Notificações utilizando React Toastify
✅ Navegação entre páginas
✅ Interface responsiva

---

## 🛍️ Como Funciona

O sistema consome uma API de produtos e exibe os itens disponíveis na loja. O usuário pode:

* Visualizar os produtos
* Adicionar produtos ao carrinho
* Remover produtos do carrinho
* Ver o valor total da compra atualizado em tempo real

Além disso, o sistema utiliza notificações com Toastify para melhorar a experiência do usuário durante as ações realizadas.

---

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de praticar:

* Consumo de APIs
* Gerenciamento de estado
* Manipulação de carrinho de compras
* Componentização no React
* Experiência do usuário com notificações
